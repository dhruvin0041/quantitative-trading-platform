HYDRA TERMINAL: INITIALIZATION FROM ZERO-STATE
==============================================

Follow these steps in order to initialize, optimize, and launch the system 
for a specific ticker (Example: RELIANCE.NS).

PREREQUISITES:
- Python 3.10+
- Node.js 20+
- Valid GOOGLE_API_KEY in backend/.env (optional for alpha research)
- Valid API_KEY in backend/.env (must match frontend/.env.local)

STEP 0: ENVIRONMENT SETUP
-------------------------
Ensure you are using the dedicated virtual environment with all dependencies.
> cd backend
> python -m venv venv
> .\venv\Scripts\activate  # Windows
> pip install -r requirements.txt

STEP 1: UNIFIED TRAINING PIPELINE
---------------------------------
Automatically executes Cleanup, Bayesian Branch Optimization, Optuna 
Ensemble Optimization, and Final Model Training in a single sequence.
(Ensure venv is activated)
> $env:PYTHONPATH='.'; python scripts/training/train.py --ticker RELIANCE.NS --trials 50

STEP 2: LAUNCH INFERENCE ENGINE (BACKEND)
-----------------------------------------
Starts the FastAPI service on http://localhost:8000.
> $env:PYTHONPATH='.'; python api.py

STEP 3: LAUNCH COMMAND CENTER (FRONTEND)
----------------------------------------
Starts the Next.js dashboard on http://localhost:3000.
(Run in a separate terminal)
> cd ../frontend
> npm run dev

==============================================
SYSTEM READY: Visit http://localhost:3000 and search for RELIANCE.NS.
