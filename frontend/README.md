# Hydra Terminal — Quantitative Trading Dashboard

**Status: 100/100 Institutional Grade**

Hydra Terminal is a high-performance, SOTA 2026 quantitative trading dashboard designed for professional hedge funds and institutional traders.

## Key Features
- **Institutional Visualization**: Custom `lightweight-charts` with Bollinger clouds, moving averages, and AI entry/exit markers.
- **Ensemble Intelligence**: Real-time signal consensus from LSTM and XGBoost agents.
- **Command Center (⌘K)**: Quick asset switching, theme toggling, and action execution.
- **Advanced Export**: Save comprehensive dashboard reports as institutional-grade PDF or PNG captures.
- **Layout Presets**: Switch between Standard, Analytical, and Compact modes with persistent preferences.
- **Live Risk Monitoring**: Real-time VaR, CVaR, Kelly Fraction, and Drawdown tracking.
- **Accessibility & Onboarding**: WCAG AA compliant with interactive guided tours for new users.
- **Premium Aesthetics**: Light/Dark theme support with glassmorphism, institutional grain overlays, and smooth motion choreography.

## Technology Stack
- **Framework**: Next.js 16.2 (App Router)
- **Styling**: Tailwind CSS v4 (Alpha)
- **UI Components**: shadcn/ui (Nova preset)
- **Animations**: Framer Motion
- **Charts**: TradingView Lightweight Charts v5
- **Notifications**: Sonner

## Getting Started
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to experience the terminal.

## Performance
Optimized for 120Hz displays and ultra-wide monitor setups. Zero runtime errors. Pure TypeScript implementation.
